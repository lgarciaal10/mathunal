# Mockups de cursos MathUNAL

Borradores de diseño del curso de Cálculo. No forman parte del sitio y no están enlazados desde `index.html`.
Todos los datos son de ejemplo. El temario real está PENDIENTE.

- `calculo-portada.html` tres variantes de la página del curso (Camino, Libreta, Mapa)
- `calculo-leccion.html` tres variantes de una lección (Pizarra, Lectura guiada, Laboratorio)

Cada archivo es autónomo, trae modo claro y oscuro y carga KaTeX 0.16.9 desde cdnjs.
