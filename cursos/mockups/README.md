# Mockups de cursos MathUNAL

Borradores de diseño del curso de Cálculo. No forman parte del sitio y no están enlazados desde `index.html`.
Los datos de ejemplo van marcados y el temario real está PENDIENTE. El mapa de temas es la excepción porque usa datos reales del banco.

Diseño elegido
- `portada-final.html` portada del curso con el diseño Libreta, animada
- `leccion-tres-modos.html` una lección con tres modos de estudio, Ver, Leer y Practicar
- `leccion-limite-1.html` la misma lección construida desde `../lecciones/calculo-limite-1.json` con el motor de `../plantilla`
- `mapa-temas-calculo.html` temas del banco de Cálculo Diferencial, Integral y Varias Variables

Galerías anteriores con las tres variantes, solo de referencia
- `calculo-portada.html`
- `calculo-leccion.html`

Todos traen los cuatro temas del sitio (Azul, Negro, Gris y Claro) y cargan KaTeX 0.16.9 desde cdnjs.
